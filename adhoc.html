That's all three done

You've now added a medicine by hand from start to finish — search, quantity, setup, schedule, check in.

  • Adhoc means you are creating the data, so the schedule never arrives ready-made — you always build it yourself before you can check in.
  • The dosage instructions must match the dispensing label on the box, word for word.
  • Round time is the time it's actually given. One round per time of day, or press Add PRN for a when-required medicine.
  • If you pick the wrong medicine in the search, press Remove and start that one again — it's easier than fixing it later.
